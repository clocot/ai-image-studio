## What it does

Not another image generator. A real layer editor on every major image model, your brand kits, an Art Director that plans the work, client approvals and every channel size. One Office, for the whole team.

## Inside the studio

| Create | Edit | Deliver |
|---|---|---|
| Every major image model, Auto picks per job | Real layers, masks and blend modes | Export to every channel |
| Ask the Art Director, in any language | Smart layers: a photo becomes layers | Smart re-framing per channel |
| Office styles from your photos | Inpaint, recolor, relight in plain words | Client approval links |
| Model Arena and your own model scoreboard | Text that stays editable | Comments pinned on the image |
| Flows and CSV batch | Vectorize to SVG | Content credentials in every file |
| Realtime canvas | Select with a brush, add or subtract | Brand Guardian |

AI Image Studio runs inside Clocot today, as part of the working prototype. The wider Clocot production platform follows in early 2027.
